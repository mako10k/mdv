# Plugin Manifest Reference

> Generated by `scripts/generate-plugin-contract.mjs` from `plugin-contract/contract.json`. Do not edit directly.

## Availability

This is an internal/experimental metadata contract for MDV maintainers and bundled-package developers. Validation does not authorize Driver execution or Skill loading, and this is not a Public SDK compatibility promise.

## Manifest

- schema version: `1`
- Plugin API version: `1`
- exact object shapes: additional properties are rejected
- package, capability, resource, and Skill IDs: `^[a-z][a-z0-9]*(?:[.-][a-z0-9]+)*$`
- versions: strict `major.minor.patch` without prerelease/build metadata
- resource paths: contained bundle-relative POSIX paths only
- resource digest: lowercase SHA-256
- capability permissions: an empty array in ENG-BL-005; validation grants no authority

The required top-level fields are `schemaVersion`, `id`, `displayName`, `version`, `compatibility`, `resources`, `capabilities`, and `skills`. See [the generated JSON Schema](../plugin-contract/manifest.schema.json) for exact nested fields and limits.

## Diagnostics

| Code | Severity | Public message | Remediation |
| --- | --- | --- | --- |
| `PLUGIN_INVALID_JSON` | `error` | The Plugin manifest is not valid JSON. | Fix the JSON syntax and run the validator again. |
| `PLUGIN_UNKNOWN_SCHEMA_VERSION` | `error` | The Plugin manifest schema version is unsupported. | Author the manifest against the generated manifest reference. |
| `PLUGIN_INVALID_MANIFEST` | `error` | The Plugin manifest does not match the required contract. | Compare the field with plugin-contract/manifest.schema.json. |
| `PLUGIN_UNSUPPORTED_CAPABILITY_VERSION` | `error` | A Plugin capability contract version is unsupported. | Use the family version listed in the generated manifest reference. |
| `PLUGIN_INCOMPATIBLE_HOST_VERSION` | `error` | The Plugin package is incompatible with this MDV version. | Update the compatibility range only after verifying the package against that host. |
| `PLUGIN_PATH_ESCAPE` | `error` | A Plugin resource path is outside its package boundary. | Move the resource under the package root and use its contained relative path. |
| `PLUGIN_MISSING_RESOURCE` | `error` | A declared Plugin resource is missing. | Add the declared file or remove the stale resource declaration. |
| `PLUGIN_DIGEST_MISMATCH` | `error` | A declared Plugin resource digest does not match its content. | Review the resource and update the digest from the intended bytes. |
| `PLUGIN_DUPLICATE_PACKAGE_ID` | `error` | More than one Plugin package declares the same ID. | Assign globally distinct package IDs. |
| `PLUGIN_DUPLICATE_CAPABILITY_ID` | `error` | More than one Plugin capability declares the same ID. | Assign globally distinct capability IDs. |
| `PLUGIN_DUPLICATE_SKILL_ID` | `error` | More than one Skill contribution declares the same ID. | Assign globally distinct Skill contribution IDs. |
| `PLUGIN_UNKNOWN_RESOURCE_REFERENCE` | `error` | A Plugin declaration references an unknown resource. | Declare the referenced resource or remove the invalid reference. |
| `PLUGIN_PACKAGE_READ_FAILED` | `error` | The Plugin package could not be read. | Restore the bundled package input and rebuild the application. |

Public diagnostics contain only bounded catalog facts, contribution state, codes, severity, and public messages. Developer validator output may additionally contain bundle-relative locations, developer detail, and remediation. Absolute package paths and raw manifests are excluded.
