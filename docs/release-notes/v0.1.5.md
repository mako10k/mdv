# MDV 0.1.5

## Highlights

- Restores the Windows installer auto-update packaging metadata so installer builds ship the updater config that electron-updater expects.

## Fixes

- Treats an installed Windows runtime that is missing app-update.yml as a broken installer setup instead of silently falling back to manual-update semantics.
- Shows the broken-installer updater error directly in About and Settings so the installation problem is visible to the user.

## Notes

- Existing broken Windows installs still need to be reinstalled from the installer once 0.1.5 artifacts are published.
