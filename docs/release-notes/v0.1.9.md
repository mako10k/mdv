# MDV 0.1.9

## Highlights

- Refactors the Electron main process into a typed controller-based structure, reducing the amount of logic still concentrated in the legacy entry surface.
- Removes the placeholder-only empty state from fresh untitled documents so new editors start from a truly blank canvas.

## Fixes

- Fixes title-update drift, tab typography mismatch, and the OpenAI `previous_response_id` handling bug tracked in GitHub issue #1.
- Aligns docs, review guidance, and workspace routing with the new `src/electron/main.*` ownership so validation and code review point at the real implementation surface.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
- This release commit includes the canonical 0.1.9 Windows host artifacts.
