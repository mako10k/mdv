# MDV 0.1.13

## Highlights

- Restores full-height rendered preview output for fenced code blocks and Mermaid diagrams.
- Keeps editor and AI chat code-block styling separated so shared class names no longer leak across surfaces.

## Fixes

- Fixes rendered preview code fences collapsing into near-line-height output by scoping preview code block CSS to the preview panel.
- Fixes Mermaid preview diagrams rendering in a tiny scrollable area by preventing chat-only Mermaid overflow styles from applying to the preview panel.
- Updates WYSIWYG fenced code blocks to use the app monospace stack instead of Toast UI's CJK fallback stack.

## Notes

- Adds Playwright coverage for rendered code fence height, Mermaid SVG height, and monospace font application.
