# MDV 0.1.7

## Highlights

- Fixes AI new-document writes so `write_target` with `editorId: ':new'` no longer opens a blank white document.

## Fixes

- Queues early AI editor requests in the preload bridge so a newly opened renderer cannot miss the initial `mdv:ai-editor-request` event during startup.
- Prevents the fresh-window baseline canonicalization path from overwriting AI-written content with the empty initial buffer after the editor mounts.
- Adds an Electron regression test that exercises `writeAiTarget` with `:new` and verifies the created window is populated.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
- Candidate and canonical Windows host artifacts for 0.1.7 must be regenerated from this release commit.
