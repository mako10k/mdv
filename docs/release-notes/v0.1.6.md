# MDV 0.1.6

## Highlights

- Fixes the fresh untitled editor crash that could blank the renderer immediately after switching to WYSIWYG mode and starting to type.

## Fixes

- Replaces the Toast UI internal placeholder widget for fresh untitled documents with an app-owned non-interactive overlay so WYSIWYG editing no longer produces invalid ProseMirror positions.
- Keeps the Markdown selection normalization path resilient against transient out-of-range WYSIWYG caret data while the editor state settles.
- Adds Electron and browser regression coverage for untitled placeholder behavior and WYSIWYG editing startup.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
- If you validate via Electron Playwright on this repo, rebuild first so the static renderer bundle reflects the latest renderer changes.
