# MDV 0.1.18

## Highlights

- Adds Reload File for the current saved Markdown file from F5, the File menu, and the topbar.
- Provides a manual fallback for clean buffers when filesystem watcher notifications are unavailable or unreliable.

## Fixes

- Keeps dirty buffers safe by skipping manual reload when the editor has unsaved changes.
- Updates the synchronized file snapshot even when a manual reload finds the file already up to date.

## Notes

- Manual reload uses the existing local file read path and does not add polling or a new preload IPC contract.
- UNC / network filesystem watcher fixes remain out of scope; this release adds a user-triggered fallback rather than a backend-specific watcher guarantee.
