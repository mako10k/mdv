# MDV 0.1.11

## Highlights

- Scopes inline code styling so WYSIWYG and rendered preview no longer inherit oversized `code` typography from outer application chrome.
- Disables the browser spellchecker inside the Toast UI editor so Markdown and WYSIWYG editing no longer show Chrome red squiggle underlines.

## Fixes

- Keeps exported rendered HTML inline code styling aligned with the live preview contract.
- Reapplies editor spellcheck suppression when Toast UI rebuilds editable roots during mode changes and focus transitions.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
