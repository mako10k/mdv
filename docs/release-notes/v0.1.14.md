# MDV 0.1.14

## Highlights

- Makes relative images render directly in WYSIWYG for both saved files and untitled draft workspaces.
- Adds a dedicated Help window from the status bar so core editing, image, AI, and update guidance no longer depends on persistent footer text.

## Fixes

- Fixes saved Markdown files showing image widgets instead of the actual image when the same relative image already renders in preview.
- Fixes untitled drafts losing the WYSIWYG image rendering path by resolving draft-workspace assets before first save.
- Fixes inline data URL image omission so the abbreviated source view still keeps the display comment editable.
- Adds browser and Electron regression coverage around WYSIWYG image resolution, draft-image first save, and draft asset cleanup.

## Notes

- This release focuses on the image experience bundle: images stay visible in WYSIWYG, survive first save more reliably, and fail more explicitly when a reference is broken.
- HTML export with relative images still works best after saving the Markdown file first.
