# MDV 0.2.0

## Highlights

- Adds an interactive review flow for eligible AI dry-run changes to the active editor document, with per-hunk apply, discard, and manual editing before those proposed changes are applied.
- Adds a GPT-5.6 model picker in Settings with Sol, Terra, and Luna options sourced from one application-owned model registry.
- Shows the selected model's provider, context window, maximum output, standard API pricing, long-context pricing condition, status, and recommended state.

## Fixes

- Revalidates AI change proposals against the live document and rejects stale proposals before writing over newer edits.
- Treats an apply with an unavailable acknowledgement as an indeterminate terminal result: the change may already have been applied, so MDV does not retry it automatically.
- Preserves legacy model settings until the user explicitly selects a supported migration target.
- Keeps Settings, runtime context budgeting, and AI application metadata aligned with the same model facts.

## Notes

- GPT-5.6 Terra is the new default model for fresh settings.
- Existing unlisted model values are retained and shown with a migration warning; saving OpenAI settings requires selecting a listed model.
- GPT-5.6 requests explicitly preserve the previous effective reasoning baseline during this migration. Reasoning controls are not added in this release.
- Interactive proposals currently cover eligible live active-editor `write_target` calls with `dryRun: true`. Non-dry writes, new-document targets, temporary buffers, and structure mutations remain on their existing paths.
- Creating a proposal ends the current model turn. After reviewing the proposal, continuing AI work requires a new user message.
