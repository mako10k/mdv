# MDV 0.1.10

## Highlights

- Cleans up editor window lifecycle so new documents open in a fresh editor window while normal open and drag-and-drop continue to load into the target window.
- Adds a resizable AI Chat dock divider and makes Ctrl/Cmd+I toggle the embedded chat dock.

## Fixes

- Removes redundant default-target wording from the embedded AI Chat dock because the dock and editor now share the same target context.
- Keeps AI `write_target` requests with `editorId=":new"` on the populated-new-window path.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
