# MDV 0.1.4

## Highlights

- Slims the top toolbar so the main workspace keeps only the primary document, insert, output, and settings actions.
- Moves editor search and replace into a dedicated dialog opened from the toolbar or with Ctrl/Cmd+F and Ctrl/Cmd+H.

## Fixes

- Disables the topbar save button until the current editor buffer is actually dirty.
- Shows the AI dock entry only when the OpenAI provider is enabled and configured, and keeps the same gate on the shortcut path.

## Notes

- Theme switching now lives in Settings instead of the top toolbar.
- Preview mode keeps the slimmer action set focused on copy, print, export, file, and settings actions.
