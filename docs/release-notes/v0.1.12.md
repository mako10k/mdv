# MDV 0.1.12

## Direct Caller Update

- This update affects only direct callers of the AI structure tools. App UI users do not need migration.
- `replace_structure(query, ...)` is no longer supported; exact replacement now requires `replace_structure(handle, ...)`, and intentional query-based batch replacement now uses `replace_all_structures(query, expectedMatchCount, ...)`.
- Exact replacement now follows `query_structure` or `list_structure_map` to get one fresh handle, then `replace_structure(handle, ...)`.
- Recommended flow for batch replacement is `query_structure` to confirm the target set, optional `dryRun: true` to preview, then `replace_all_structures` with the confirmed `expectedMatchCount`.

## Highlights

- Splits structure replacement into two explicit tools so exact single-node replacement and deliberate multi-node replacement are no longer mixed in one contract.
- Makes single-node structure replacement require a previously returned handle, removing the path where a broad selector can be "fixed" by widening the replacement scope.

## Fixes

- Adds `replace_all_structures` with required `expectedMatchCount`, so a failed single-target replace no longer widens into an accidental multi-node replace.
- Adds `dryRun` support for structure replacement planning and updates help, tests, and ADR/design docs to match the new tool contracts.

## Notes

- This contract hardening was added to block an observed failure mode where a single-node replace attempt broadened into a 79-node query replace.
