# MDV 0.1.1

## Highlights

- Improved OpenAI Responses streaming handling so streamed chat replies finalize correctly on Windows.
- Hardened Windows host packaging so the full release build can be reproduced reliably from WSL.

## Fixes

- Switched the OpenAI streaming reply finalization path to prefer the official `response.output_text.done` event when `finalResponse().output_text` is missing.
- Added a narrow TS-checked OpenAI stream boundary to catch SDK contract drift during build.
- Added Windows host packaging fallbacks for file hashing and explicit copying of build resources needed by `electron-builder`.

## Notes

- This release is a patch release on the existing 0.1 feature line; no migration is required.
- Windows artifacts for this release are built from the tagged 0.1.1 release commit and should not be mixed with older 0.1.0 binaries.
