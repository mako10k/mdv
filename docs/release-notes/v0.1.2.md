# MDV 0.1.2

## Highlights

- Corrected the GitHub Release packaging flow so portable and installer binaries publish as distinct assets.
- Supersedes the incomplete 0.1.1 GitHub release asset set.

## Fixes

- GitHub release uploads now stage unique public asset names for the portable executable, installer executable, and installer blockmap.
- Added release workflow coverage to prevent future asset-name collisions from regressing silently.

## Notes

- This is a corrective patch release on the same 0.1 feature line; no migration is required.
- Prefer the 0.1.2 GitHub release assets over 0.1.1 when downloading Windows binaries.
