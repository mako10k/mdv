# MDV 0.2.1

## Highlights

- Opens rendered Markdown links without navigating the MDV application window away from the current document.
- Opens existing relative, absolute, and `file:` local-file targets in MDV, while HTTP(S) links continue through the confirmation policy to the default browser.

## Fixes

- Reuses and focuses an existing MDV editor when the linked local file is already open.
- Blocks missing files, directories, unsupported schemes, scripted top-level navigation, and renderer-created windows without replacing the current MDV screen with an error or blank page.
- Keeps local-file subresources outside packaged application assets blocked; clicking a local document link does not grant Markdown or raw HTML images access to arbitrary local files.
- Retries UNC file-watcher failures with bounded backoff and suppresses repeated log noise while preserving the manual reload fallback.
- Updates Markdown parsing dependencies and binds Toast UI Editor to the exact DOMPurify 3.4.12 sanitizer used by the shipped renderer bundle.

## Notes

- Relative links require a saved source document so MDV can resolve the target from its containing folder.
- Local link targets must be regular files. Directory browsing and cross-document fragment jumps are not included in this release.
