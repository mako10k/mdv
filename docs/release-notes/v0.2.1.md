# MDV 0.2.1

## Highlights

- Opens rendered relative, absolute, and `file:` local-file links in MDV while keeping the source document open.
- Opens permitted HTTP(S) links in the default browser through the existing external-link confirmation flow.

## Fixes

- Prevents preview and WYSIWYG links, scripted navigation, and new-window requests from replacing an MDV application page with an invalid target and leaving a blank window.
- Reuses an existing MDV window when the linked local file is already open, and fails safely for missing files, directories, unsupported schemes, and unsaved-document relative links.
- Protects packaged renderer pages from user-controlled local-file subresource loading while keeping user-activated local document links available through the desktop bridge.
- Backs off repeated tracked-file watcher failures from 1 second to 5 seconds, 30 seconds, and then 5 minutes, suppressing repeated warning-log growth while manual reload remains available.
- Updates Markdown parsing, link detection, YAML parsing, and the editor's active HTML sanitizer to patched versions after the release preflight found known production-dependency advisories.

## Notes

- Local links open regular files only. Directory browsing, custom protocols, and cross-document heading jumps are outside this release.
- Managed-client mode keeps its existing window topology and does not open local-link targets in another editor window.
