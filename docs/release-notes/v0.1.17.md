# MDV 0.1.17

## Highlights

- Adds Markdown table commands for inserting and formatting tables, adding rows, adding columns, and changing the current column alignment.
- Groups table commands under a Table actions menu so the expanded table command set stays reachable without crowding the topbar.
- Adds task checkbox assistance for toggling existing task items and converting selected list items into unchecked task items.

## Fixes

- Keeps table commands scoped to top-level rendered GFM table blocks and reports no target outside rendered table blocks.
- Preserves adjacent non-table pipe blocks and existing alignment while formatting tables or adding columns.
- Keeps the table action menu above the editor surface in narrow and normal editor layouts.
- Keeps search dialog modality above the topbar after the table menu layering change.

## Notes

- Updates the backlog record for the completed current accepted MD-BL-006 table editing scope, MD-BL-007 list assistance scope, and MD-BL-013 current accepted command-surface gate.
- Broader command palette, shortcut overlay, additional table structural operations, and full command surface redesign remain future scope.
