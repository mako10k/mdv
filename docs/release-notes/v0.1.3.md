# MDV 0.1.3

## Highlights

- Adds Windows installer auto-update support for installed release builds.
- Keeps portable builds on manual updates while surfacing updater state in About and Settings.

## Fixes

- Ships the installer update manifest and release validation needed by electron-updater.
- Aligns GitHub release assets, latest.yml, and release checks so the published installer can resolve updates correctly.

## Notes

- Portable builds remain manual-update only.
- This release supersedes 0.1.2 for users who want updater-enabled Windows installer builds.
