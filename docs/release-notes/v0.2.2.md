# MDV 0.2.2

## Highlights

- Opens rendered Mermaid diagrams from the document preview or AI chat in a dedicated desktop viewer.
- Lets you zoom, reset, scroll, and drag-pan large diagrams without changing the Markdown document layout.

## Fixes

- Reuses one viewer per editor window and closes the viewer with its owning editor.
- Buffers the initial diagram in the preload bridge so it is not lost while the viewer renderer starts.
- Keeps arbitrary rendered HTML and SVG out of the IPC boundary; the viewer accepts bounded Mermaid source and an explicit theme.
- Extends packaged renderer security validation and release fingerprinting to the Mermaid viewer entry.

## Notes

- Viewer zoom and pan are temporary and do not change Markdown, exported HTML, or saved settings.
- This release adds only the built-in Mermaid viewer. It does not add a reusable viewer or plugin API for images, tables, math, or other content types.
