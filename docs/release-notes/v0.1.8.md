# MDV 0.1.8

## Highlights

- Adds app-wide typography controls with focus-aware shortcuts, including reset via Ctrl+0 and size changes via Ctrl++ / Ctrl+- on the active surface.
- Keeps the AI chat header explicit about the current default write target so multi-editor work is less ambiguous.

## Fixes

- Applies saved editor and AI chat font sizing consistently across the desktop UI and makes the settings screen denser so typography tuning is practical.
- Refines the preview active-heading treatment so H3/H4 headings keep their reset chrome while the active location remains visible.
- Adds focused Playwright coverage for preview and WYSIWYG heading rendering, and includes the desktop bridge typings in the Playwright TypeScript config so those checks fail earlier when the contract drifts.

## Notes

- This is a patch release on the existing 0.1 feature line; no migration is required.
- This release commit includes the canonical 0.1.8 Windows host artifacts.
