# Release Work Memo v0.2.3 (candidate complete, unpublished)

この文書は v0.2.3 release gate evidence の正本とする。

画面を超える Mermaid zoom と両軸 scroll の修正、Windows candidate、packaged smoke、canonical promotion は完了した。依存関係監査の既知 findings は受容しているが、publication は release commit、clean-worktree check、remote SHA、tag、GitHub Release と asset readback が完了するまで未実施である。

## Scope

- v0.2.2 Mermaid viewer の zoom が window 内へ収まり、拡大後の領域を scroll できなかった不具合を修正する。
- Mermaid SVG の viewBox 寸法を基準に拡大後 canvas の width / height を確保し、両軸の native scroll と既存 drag pan から到達可能にする。
- Plugin / driver API、永続 zoom、Markdown / export mutation は対象外。

## Validation

- `npm run lint`: pass.
- `npm run build`: pass; both packaged renderer entry bundle checks passed.
- focused Mermaid viewer browser regression: 100% から 400% で両軸 scroll extent が増加し、両軸とも viewport を超え、scroll end へ到達することを確認済み（2 pass）。
- `npm run test:release`: 31 pass.
- `npm run test:node`: 121 pass.
- full browser Playwright: 80 pass / 1 fail。失敗した非 Mermaid test は `cancels the main proposal if detail loading fails` で、一時 status 表示の 5 秒 timeout。Mermaid viewer の2 test は同じ full run で passし、失敗 test の focused rerun も 1 pass したため、この release scope と無関係な timing failure と判断した。
- Electron E2E: 51 pass.
- `npm audit --omit=dev`: 7 findings（high 3、moderate 4）。Windows packaging install: 26 findings（critical 3、high 18、moderate 4、low 1）。v0.2.2 から dependency graph は不変で、この release は findings の解消や非到達性を主張しない。本 runbook に audit-zero gate はなく、今回の修正と dependency remediation を混ぜず、既知 runtime/build risk をこの release 判断で明示的に受容して別 scope へ送る。
