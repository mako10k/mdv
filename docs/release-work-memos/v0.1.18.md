- Patch release for manually reloading the current saved Markdown file when watcher notification delivery is unavailable or unreliable.
- Adds F5, File menu, and topbar Reload File entry points for clean saved buffers.
- Preserves dirty-buffer safety by skipping reload when the editor has unsaved changes.
- Records the active local file sync contract in `docs/local-file-sync-design.md` and keeps UNC / backend-specific watcher fixes out of this release scope.
