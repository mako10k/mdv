# Release Work Memo v0.2.2 (candidate complete, unpublished)

この文書は v0.2.2 release gate evidence の正本とする。

Windows candidate の生成、実アプリ経路での Mermaid viewer 確認、canonical artifact への promotion は完了した。依存関係監査の既知 findings は残るが、v0.2.1 から依存グラフを変更しておらず、この release の必須 gate は audit zero を要求していないため、未解消リスクを明示して publication gate へ進む。release commit、clean-worktree check、remote SHA、tag、GitHub Release と asset readback は未完了であり、現時点では未公開である。

## Scope

- Dedicated Mermaid viewer window for rendered diagrams in document preview and AI chat.
- Viewer-local zoom, reset, native scrolling, modified-wheel zoom, and pointer drag panning without Markdown or export mutation.
- Main-owned one-viewer-per-editor lifecycle。プロセス間では Mermaid text と theme だけを渡し、任意 HTML/SVG は渡さない。起動時 payload の保持、外部 navigation の拒否、owner editor と一緒に閉じる挙動を含む。
- Multi-entry release fingerprint and packaged sanitizer checks for `dist/index.html` and `dist/mermaid-viewer.html`.
- この patch は built-in Mermaid viewer だけを追加する。他の content type が再利用できる汎用 viewer/plugin API は追加しない。

## Early Contract Review

- Feature implementation used the worktree/staged diff against `HEAD` as the reviewed target before broad regression and Windows packaging.
- Initial consistency review found that non-editor senders could reach the Mermaid viewer IPC and that promised evidence was broader than the tests. The IPC now rejects non-editor senders, viewer navigation/new-window denial has targeted coverage, and evidence claims are narrowed to executed gates.
- Initial packaging review found that `mermaid-viewer.html` was absent from release source fingerprinting and packaged security validation. The fingerprint, local bundle check, packaged `app.asar` validation, fixtures, and operator docs now cover both renderer entries.
- Final exact-diff consistency review found an initial-payload race between `did-finish-load` and React subscription. The preload bridge now buffers the latest payload and replays it to late subscribers.
- Feature の final review 時点では real Electron route と Windows packaged smoke が evidence gap だった。その後、この release-stage validation で下記の Electron manual smoke と packaged candidate spot check を実施し、初期表示・zoom・viewer reuse を確認した。owner close、pointer pan、navigation denial は real/packaged route では個別に再実行しておらず、Node/browser test evidence に留まる。
